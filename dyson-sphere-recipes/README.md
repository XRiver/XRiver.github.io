# 戴森球计划 · 合成树助手

一个单页网页工具，以**分层合成树**展示《戴森球计划》全部 174 个物品 / 161 条生产配方（游戏版本 **0.10.34**）的上下游关系，并支持聚焦、配方开关与资源模式。

## 直接使用

用浏览器打开 `index.html` 即可（纯静态，无依赖，可离线）。或启动任意静态服务器：

```bash
cd 本目录
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123
```

目录结构：

```
index.html      页面与样式
app.js          前端逻辑（图布局 / 交互）
data.js         生成的游戏数据（items / recipes / 中文名）
icons/          物品原版图标（174 张）
tools/          数据生成与图标下载脚本（可选）
```

## 核心功能

1. **分层合成树**：按最长路径把物品分成 11 层（左=原料 → 右=深加工产物），重心排序减少连线交叉，长跨度连线自动淡化，短距离生产关系清晰呈现。

2. **聚焦重排**：点击物品进入**聚焦模式**——只保留它的上游依赖树并**重新分层、放大**；右侧面板显示配方、直接原料、用途、上游清单。点空白 / `Esc` / 「← 返回」切回全景。

3. **多配方开关 · 缩减上游**：选中物品的「生产配方」卡片可禁用/启用其配方；面板里的**「上游配方」**一节更能直接启用/禁用**任意上游物品**的配方——禁用后该分支会从高亮树中剔除，从而按你的路线一步步缩减上游。全部禁用才产出的物品不会残留。

4. **资源模式**：顶栏「资源模式」勾选当前可采集的基础资源（矿脉 / 海洋 / 气态巨行星 / 树木植物），系统自动高亮所有可向下合成的产物，统计可合成数量，不可合成的变暗。

## 其他

- 每个物品同时显示**原版图标 + 官方中文名**；悬停看英文名与配方详情；`×N` 徽标表示该物品有 N 条已启用的配方。
- **中/英文切换**：左上角开关一键切换界面与物品语言（默认中文）。
- 搜索框支持中英文名定位；顶栏提供「配方管理」（批量启用/禁用）与「帮助」。
- 状态（已禁用配方、已选资源、资源模式开关）会保存在浏览器本地存储，下次自动恢复。

## 重新生成数据（可选）

```bash
# 1. 用 dsp-wiki.com 的官方协议数据（/tmp/protosets.json）生成 data.js
python3 tools/build_data.py

# 2. 重新下载图标（需要网络）
python3 tools/dl_icons.py
```

数据与中文名来源：dsp-wiki.com 的游戏协议导出（`Module:GameData/protosets.json`）；中文名为游戏官方本地化文本（bilibili 戴森球计划 WIKI 的「本地化」页）；图标为游戏原版图标（dsp-wiki.com）。
